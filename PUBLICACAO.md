# Publicação gratuita

O repositório deste projeto é https://github.com/luizrianelli/MeuPortifolio.
O endereço gratuito configurado para este projeto é https://luizrianelli.github.io/MeuPortifolio/.

O GitHub Pages pode hospedar este site estático usando um repositório público no plano GitHub Free. Configure Settings → Pages → Deploy from a branch → main → /(root). Não há instalação de dependências nem etapa de build própria; `_config.yml` exclui as ferramentas locais de manutenção da publicação.

Nenhum domínio pago é necessário. `luizrianelli.dev` depende de registro e renovação em um registrador; não foi registrado nem configurado. O projeto não contém CNAME para esse endereço. Disponibilidade e preços não foram confirmados.

O currículo e a foto incluídos em `assets/` e `imagens/` fazem parte do site público. A atualização de currículo continua sendo local: executar `node preview.mjs`, abrir a ferramenta de atualização e enviar o PDF; depois versionar e enviar o novo arquivo ao repositório.

Para um endereço gratuito mais curto, `https://luizrianelli.github.io/`, seria necessário um repositório específico chamado `luizrianelli.github.io`; esta entrega usa o repositório já existente.

Referência: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
